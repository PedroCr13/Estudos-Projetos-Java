# Disciplina: Frameworks

Este diretório reúne os projetos e atividades desenvolvidos na disciplina **Frameworks**, com foco em aplicações cliente-servidor e no uso do **Angular** como framework front-end.

## Conteúdos abordados

- **Arquitetura cliente-servidor**  
  - Responsabilidades do **back-end** e do **front-end** em uma aplicação.
  - Comunicação entre camadas utilizando **métodos HTTP** e **APIs**.

- **Fundamentos de desenvolvimento web**  
  - Estruturação de páginas com **HTML**.  
  - Estilização com **CSS**.  
  - Dinâmica e interatividade com **JavaScript**.  
  - Tipagem e organização com **TypeScript**.

- **Angular (versão 21)**  
  - Criação de componentes.  
  - Formulário de **cadastro**.  
  - Formulário de **pesquisa**.  
  - Uso de **Input, Output e EventEmitter** para comunicação entre componentes.  
  - Aplicação de estilos com **ngStyle** e **ngClass**.  
  - Integração de bibliotecas externas: **PrimeNG** e **Prime Icons**.

## Projetos desenvolvidos

- **Introdução a Angular e criação de componentes**  
- **Formulário de cadastro de funcionários e departamentos**  
- **Formulário de pesquisa com tabela e botões**  
- **Binding com Input, Output e EventEmitter**  
- **Adição de CSS em componentes (ngStyle e ngClass)**  
- **Aplicação completa de funcionários e departamentos**

## Tecnologias utilizadas

- **Angular 21**
- **TypeScript**
- **PrimeNG**
- **Prime Icons**
- **HTML5 / CSS3 / JavaScript**
