# Simulador de Salário

Aplicativo Android desenvolvido em **Java** com o objetivo de realizar simulações de salário líquido.  
Permite ao usuário configurar diferentes variáveis que impactam no rendimento final, como:

- Dependentes
- Percentual de contribuição para previdência privada complementar
- Plano de saúde
- Sindicato/associação
- Vale transporte

---

## Funcionalidades

- Cálculo automático do salário líquido com base nas informações fornecidas.
- Interface simples e intuitiva para inserção de dados.
- Possibilidade de simular diferentes cenários e comparar resultados.
- Estrutura modular para fácil manutenção e expansão futura.

---

## Tecnologias Utilizadas

- **Java** (linguagem principal)
- **Android SDK**
- **Gradle** (gerenciamento de dependências)
- **XML** (layouts e UI)
