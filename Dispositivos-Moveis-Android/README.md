# Disciplina: Dispositivos Móveis

Este diretório reúne os projetos e atividades desenvolvidos na disciplina **Dispositivos Móveis** da pós-graduação, com foco em programação Android nativa e na construção de um aplicativo pessoal de **Controle de Abastecimento Veicular**.

## Conteúdos abordados

- **Introdução à plataforma Android**
- **Ambiente de desenvolvimento Android Studio**
- Uso do **emulador** e de **dispositivo real**
- Estrutura de um projeto Android
- Componentes básicos:
  - `TextView`, `EditText`, `Button` e `Toast`
  - `CheckBox` e `RadioButton`
  - `Spinner`
  - `ScrollView`
  - `ListView`
  - `RecyclerView`
- **Temas, estilos e ícones**
- **Transição entre Activities**
- **Menus de opção e de contexto**
- **Menu de ação contextual**
- **Botões Up**
- **Shared Preferences**
- **Internacionalização**
- **API Room Persistence**

## Projeto desenvolvido: Controle de Abastecimento Veicular

Durante as aulas, foi construído passo a passo um aplicativo Android para controle de abastecimentos, com as seguintes funcionalidades:

- **Tela de listagem de abastecimentos**
- **Tela de cadastro de abastecimentos**
- **Tela "Sobre" com informações do aplicativo**
- Persistência de dados utilizando **Room Persistence API**
- Configurações salvas com **Shared Preferences**
- Interface adaptada com **temas, estilos e ícones**
- Suporte a **internacionalização**

## Tecnologias utilizadas

- **Android Studio**
- **Java/Kotlin**
- **Room Persistence API**
- **Shared Preferences**
- **Componentes nativos Android**
