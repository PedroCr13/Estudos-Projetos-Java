# CursoJavaBase

Subdiretório contendo exercícios e pequenos projetos desenvolvidos durante o estudo dos **fundamentos da linguagem Java**. Os exemplos abordam desde operações básicas até interfaces gráficas com Swing e JavaFX.

---

## Objetivo

Este repositório tem como finalidade reunir os principais conceitos da linguagem Java por meio de projetos práticos e didáticos. Cada pasta representa um exercício ou aplicação voltada para o aprendizado incremental da linguagem.

---

## Conteúdos abordados

- Tipos primitivos e operadores
- Controle de fluxo (condições e repetições)
- Manipulação de Strings e números
- Interfaces gráficas com **Swing** e **JavaFX**
- Estrutura de programas e boas práticas
